# Greece — legislation as Markdown (LawCodex)

Work in progress: Greek primary legislation (Σύνταγμα, κώδικες, νόμοι, προεδρικά διατάγματα,
πράξεις νομοθετικού περιεχομένου) converted to Markdown from the Government Gazette (ΦΕΚ)
published by the National Printing Office (Εθνικό Τυπογραφείο, https://search.et.gr).
See the final README for coverage and caveats.
